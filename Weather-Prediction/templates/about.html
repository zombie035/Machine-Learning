About This Project

This is a beginner-level college mini project demonstrating the application of Machine Learning in web development.

Technologies Used

  • Backend: Python, Flask
  • Machine Learning: Scikit-learn (Random Forest Classifier), Pandas, NumPy
  • Frontend: HTML5, Vanilla CSS (Glassmorphism design), JavaScript

How it Works

The application uses a synthetic dataset of weather parameters to train a Random Forest model. When a user submits new weather conditions through the prediction form, the Flask backend passes these values to the saved model (`weather_model.pkl`), which predicts the most likely weather state and returns it to the UI.
